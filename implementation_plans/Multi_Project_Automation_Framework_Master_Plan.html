1. Executive Summary & Core Pillars

This master implementation plan establishes an enterprise-grade, highly repeatable web test automation framework. It eliminates common bottlenecks in modern Single Page Application (SPA) testing—such as viewport clipping, responsive layout collapse, dynamic timing anomalies, overlay click interception, and test data collision.

Any developer or QA engineer can use this exact blueprint to automate new modules (e.g., Lumpsum, SIP, STP, SWP, Switch, or Mandates) in under 15 minutes by adhering to the following five golden pillars:

Pillar Implementation Rule Benefit & Protection
1. Centralized Routing All base domains, portal prefixes, and route endpoints reside exclusively inside data/urls.py (AppURLs). Switch test environments across entire test suites instantly via TEST_ENV=QA or UAT without modifying page objects or tests.
2. True Desktop Maximization Configure both no_viewport=True in browser_context_args and --start-maximized in browser_type_launch_args. Prevents responsive frameworks (Tailwind, Radix UI) from collapsing desktop tables, forms, and buttons into mobile hamburger drawers.
3. Traceable Screenshots Every capture call inside BasePage uses full_page=True, animations="disabled" saved into screenshots/<PageObjectClassName>/. Captures entire scrollable forms without anti-aliasing artifacts or visual blurring; organized dynamically per screen.
4. Page Object Model (POM) Strict separation of locators and UI actions inside pages/. Tests contain only linear business logic and assertions. Zero raw selectors in test files. Changes in UI locators require updates in only a single page class.
5. Dual-Engine Execution Pytest runner for visual E2E verification (--headed --slowmo 500) and Excel Data-Driven runner for automated regression & audit reporting. Supports both interactive debugging and spreadsheet-driven compliance audits with automatic PASS/FAIL results recording.

3. Centralized URL Management (`data/urls.py`)

Hardcoding URLs across page objects or tests causes catastrophic maintenance failures when switching environments. All environments (LOCAL, QA, UAT, PROD) and route structures are maintained inside data/urls.py: 

import os

class AppURLs:
    """
    Single Source of Truth for base domains and route paths.
    Switch environments via TEST_ENV=QA or TEST_ENV=UAT (defaults to UAT).
    """
    ENV_DOMAINS = {
        "LOCAL": "http://localhost:3000",
        "QA": "https://investorqa.abslmfbeta.com",
        "UAT": "https://investoruat.abslmfbeta.com",
        "PROD": "https://mutualfund.adityabirlacapital.com",
    }

    ACTIVE_ENV = os.getenv("TEST_ENV", "UAT").upper()
    BASE_DOMAIN = ENV_DOMAINS.get(ACTIVE_ENV, ENV_DOMAINS["UAT"])
    PORTAL_PREFIX = "/mf-investor"
    BASE_URL = f"{BASE_DOMAIN}{PORTAL_PREFIX}"

    # Route Paths (Relative)
    LOGIN_PATH = f"{PORTAL_PREFIX}/login"
    DASHBOARD_PATH = f"{PORTAL_PREFIX}/dashboard"
    MULTISIP_PATH = f"{PORTAL_PREFIX}/multi-sip"
    MULTISIP_DIY_PATH = f"{PORTAL_PREFIX}/multi-sip/diy"
    PAYMENT_PATH = f"{PORTAL_PREFIX}/multi-sip/payment?type=diy"
    SUCCESS_PATH = f"{PORTAL_PREFIX}/multi-sip/success"

    # Absolute URLs
    LOGIN_URL = f"{BASE_DOMAIN}{LOGIN_PATH}"
    DASHBOARD_URL = f"{BASE_DOMAIN}{DASHBOARD_PATH}"
    MULTISIP_URL = f"{BASE_DOMAIN}{MULTISIP_PATH}"
    MULTISIP_DIY_URL = f"{BASE_DOMAIN}{MULTISIP_DIY_PATH}"
    PAYMENT_URL = f"{BASE_DOMAIN}{PAYMENT_PATH}"
    SUCCESS_URL = f"{BASE_DOMAIN}{SUCCESS_PATH}"

    # Dynamic Route Builders for Custom Modules (e.g. Lumpsum or Specific Schemes)
    @classmethod
    def get_lumpsum_config_url(cls, scheme_code: str = "251GZ") -> str:
        return f"{cls.BASE_URL}/invest/lumpsum?schemeCode={scheme_code}"

    @classmethod
    def get_payment_url(cls, journey_type: str = "lumpsum") -> str:
        return f"{cls.BASE_URL}/payment?type={journey_type}"

4. Desktop Window Maximization Fix (`conftest.py`)

Playwright's default emulated 1280x720 viewport breaks modern desktop layouts. In responsive frameworks (Tailwind, Bootstrap, Radix UI), wide multi-fund tables collapse and sticky action bars hide behind off-screen drawers.

To resolve this permanently, configure both no_viewport=True on the browser context and --start-maximized on browser launch: 

import os
import sys
from pathlib import Path
import pytest
from dotenv import load_dotenv

# Ensure all sub-packages resolve in sys.path
PROJECT_ROOT = Path(__file__).resolve().parent
for directory in (PROJECT_ROOT / "multisip_test", PROJECT_ROOT):
    dir_str = str(directory)
    if dir_str not in sys.path:
        sys.path.insert(0, dir_str)

load_dotenv()

def pytest_addoption(parser):
    parser.addoption(
        "--env",
        action="store",
        default=os.getenv("TEST_ENV", "UAT"),
        help="Target test environment: LOCAL, QA, UAT, PROD",
    )

@pytest.fixture(scope="session", autouse=True)
def set_test_env(pytestconfig):
    env = pytestconfig.getoption("env").upper()
    os.environ["TEST_ENV"] = env
    return env

@pytest.fixture(scope="session")
def browser_context_args(browser_context_args):
    """Disable emulated fixed viewport so window dictates true dimensions."""
    return {
        **browser_context_args,
        "no_viewport": True,
    }

@pytest.fixture(scope="session")
def browser_type_launch_args(browser_type_launch_args):
    """Launch maximized desktop browser; headed by default, configurable for CI."""
    is_headless = os.getenv("HEADLESS", "false").lower() in ("true", "1", "yes")
    return {
        **browser_type_launch_args,
        "headless": is_headless,
        "args": ["--start-maximized"],
    }

5. Core Interaction Wrapper (`pages/base_page.py`)

The BasePage class provides standardized browser primitives, handles slow character typing, bypasses transparent backdrop overlays using JavaScript evaluation, and enforces full-page screenshot capturing into class-segregated directories: 

import os
import time
from playwright.sync_api import Page, Locator, TimeoutError as PlaywrightTimeoutError

class BasePage:
    def __init__(self, page: Page):
        self.page = page

    def go_to(self, url: str):
        self.page.goto(url)
        self.page.wait_for_load_state("domcontentloaded")
        self.take_screenshot("navigation")

    def click(self, locator: str, name_for_screenshot: str = "click", force: bool = False):
        self.page.locator(locator).click(force=force)
        self.take_screenshot(name_for_screenshot)

    def js_click(self, locator: str, name_for_screenshot: str = "js_click"):
        """Bypasses transparent modals, loaders, or sticky headers via native DOM click."""
        self.page.locator(locator).evaluate("node => node.click()")
        self.take_screenshot(name_for_screenshot)

    def slow_fill(self, locator: str, text: str, delay_ms: float = 80, name_for_screenshot: str = "fill"):
        loc: Locator = self.page.locator(locator)
        loc.clear()
        for char in str(text):
            loc.type(char, delay=delay_ms)
        self.take_screenshot(name_for_screenshot)

    def select_option_by_value(self, locator: str, value: str, name_for_screenshot: str = "select"):
        self.page.locator(locator).select_option(value=value)
        self.take_screenshot(name_for_screenshot)

    def select_option_by_label(self, locator: str, label: str, name_for_screenshot: str = "select"):
        self.page.locator(locator).select_option(label=label)
        self.take_screenshot(name_for_screenshot)

    def wait_for_selector(self, locator: str, state: str = "visible", timeout: float = 30000):
        self.page.wait_for_selector(locator, state=state, timeout=timeout)

    def is_visible(self, locator: str, timeout: float = 5000) -> bool:
        try:
            self.page.wait_for_selector(locator, state="visible", timeout=timeout)
            return True
        except PlaywrightTimeoutError:
            return False

    def wait_for_url_contains(self, text: str, timeout: float = 30000):
        self.page.wait_for_url(lambda url: text in url, timeout=timeout)

    def wait(self, ms: int):
        self.page.wait_for_timeout(ms)

    def take_screenshot(self, name: str) -> str:
        """Captures unblurred full-page screenshots in class-named folders."""
        page_name = self.__class__.__name__
        base_dir = os.path.dirname(os.path.dirname(os.path.abspath(__file__)))
        screenshot_dir = os.path.join(base_dir, "screenshots", page_name)
        os.makedirs(screenshot_dir, exist_ok=True)

        timestamp = int(time.time() * 1000)
        screenshot_path = os.path.join(screenshot_dir, f"{name}_{timestamp}.png")
        self.page.screenshot(path=screenshot_path, full_page=True, animations="disabled")
        return screenshot_path

6. Modern SPA Locator Guidelines & Radix UI Patterns

UI Component HTML / Radix Characteristic Recommended Locator Pattern
Custom Checkbox <button role="checkbox" data-state="unchecked"> Check get_attribute("data-state") != "checked" before clicking to prevent accidental unchecking.
Accordions / Drawers <button aria-expanded="false" data-state="closed"> Click accordion header, wait for data-state="open", then click the child option inside.
Split OTP Inputs 4 separate inputs with aria-label="OTP digit 1..4" Iterate through digit inputs sequentially with 150ms delay between keypresses to trigger JavaScript event listeners.

7. Dynamic Test Data Engine (`utils/data_generator.py`)

To prevent collision during parallel or repeated test executions, static user data should be minimized. The dynamic generator creates realistic, valid test inputs: 

import random
import string
from datetime import datetime, timedelta

def calculate_t_plus_days(days: int = 6, skip_weekends: bool = False) -> str:
    """Calculates T+N date formatted as DD/MM/YYYY for SIP and settlement dates (T+6 for ABSLMF Multi-SIP)."""
    current_date = datetime.now()
    if not skip_weekends:
        target_date = current_date + timedelta(days=days)
    else:
        added = 0
        target_date = current_date
        while added < days:
            target_date += timedelta(days=1)
            if target_date.weekday() < 5:  # Monday to Friday
                added += 1
    return target_date.strftime("%d/%m/%Y")

def generate_random_mobile() -> str:
    """Generates a random 10-digit Indian mobile number."""
    prefix = random.choice(["9", "8", "7", "6"])
    suffix = "".join(random.choices(string.digits, k=9))
    return f"{prefix}{suffix}"

def generate_random_email() -> str:
    """Generates a safe synthetic test email address."""
    rnd = "".join(random.choices(string.ascii_lowercase + string.digits, k=8))
    return f"uat_investor_{rnd}@example.com"

8. Data-Driven Excel Testing Engine

The framework includes a fully integrated Excel test execution engine that audits every test row, runs the corresponding automation journey, captures evidence screenshots, and records the results into a timestamped output workbook without mutating the original template.

Core Workflow:

  1. Scaffold Matrix: Run python <module>_test/utils/generate_test_cases.py to create the structured workbook covering Positive, Negative, and Boundary cases.
  2. Data-Driven Runner: tests/run_excel_tests.py reads each row via ExcelManager.
  3. Audit Logging: On completion, updates the row with PASS or FAIL, the actual outcome string, failure stack trace, and full-page screenshot path.
  4. Non-Destructive Output: Saves to <filename>_results_YYYYMMDD_HHMMSS.xlsx to preserve historical audit logs.

9. Step-by-Step Blueprint to Clone for Any New Module

To stand up a new journey (e.g. Lumpsum, STP, Switch, or Redemption), follow these 7 systematic steps:

Step Action Detailed Implementation
Step 1 Clone Repository Structure Copy the folder structure. Rename package to <module>_test/ (e.g., lumpsum_test/). Keep root conftest.py and requirements.txt.
Step 2 Define Central Routes In data/urls.py, add the new module's relative endpoints (e.g. LUMPSUM_PATH = f"{PORTAL_PREFIX}/invest/lumpsum").
Step 3 Define Module Constants In data/test_data.py, add module-specific amounts, scheme codes, and default test inputs. Keep sensitive credentials linked to os.getenv().
Step 4 Create Page Objects Inherit from BasePage. Implement screens: LumpsumLandingPage, LumpsumConfigPage, and reuse LoginPage and PaymentPage.
Step 5 Build Linear Pytest Journey Create tests/test_<module>_flow.py. Connect POM methods into a clean, human-readable user journey with step assertions.
Step 6 Generate Test Matrix In utils/generate_test_cases.py, define Positive, Negative, and Boundary scenarios for the new module. Run to generate Excel workbook.
Step 7 Map Excel Runner In tests/run_excel_tests.py, map the new Test_ID cases to the corresponding POM actions.
